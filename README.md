## 📖 نظرة عامة

**EmuCams** هو مستودع شخصي يهدف إلى تجميع وتنظيم أحدث إصدارات محاكيات:

- 🟢 **Oscam**
- 🔵 **NCam**

بصيغة **`.ipk`** جاهزة للتثبيت مباشرة على أجهزة **Enigma2** (رسيفرات Linux).

المحاكيات مأخوذة من **مطورين مختلفين** ومجمّعة في مكان واحد لسهولة الوصول والاستخدام الشخصي.

> ⚠️ **تنبيه:** هذا المستودع للأغراض الشخصية والتعليمية فقط. لا يتحمل صاحبه أي مسؤولية عن سوء الاستخدام.
